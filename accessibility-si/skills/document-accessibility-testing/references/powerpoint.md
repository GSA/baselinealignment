# PowerPoint authoring and testing

Use this reference with the full criterion and Document Baseline references. Evaluate the intended reading and presentation modes and any PDF or video export separately.

## Create or remediate

- Use structured slide layouts and descriptive titles; identify slides meaningfully even when a visual design omits a displayed title. Keep title objects in a sensible reading sequence.
- Set language, use native lists and clear links, and arrange meaningful objects in a coherent exposed order. Visual stacking order is not by itself proof of reading order.
- Provide equivalent alternatives for graphics, diagrams and charts; mark true decoration appropriately. Make data relationships available through accessible tables or explanation.
- Use readable contrast and non-color cues. Check slide masters, themes, tables, shapes and speaker-facing or participant-facing materials actually delivered.
- Supply captions, description and transcripts where required for media. Do not treat speaker notes or a general transcript as synchronized captions.
- Make interactive elements and playback controls keyboard operable with visible focus and meaningful names. Avoid unexpected context changes and uncontrolled timing.
- Give users control of qualifying animations and slide timing. Evaluate flashing with an appropriate safe method. Prefer design choices that preserve information in static delivery.

## Evaluate

Run the checker and inspect slide titles, content order and object alternatives. Navigate/read slides with the intended assistive technology; compare exposed meaning with the visual presentation. Test links, media, embedded objects, timed states and any interactive exercise in delivery mode. Test supplemental orientation, reflow/spacing and target criteria using WCAG2ICT and actual reader capabilities; record justified applicability decisions.

Evaluate exported PDF and video as delivered artifacts. Verify PDF structure and order, and verify captions/descriptions in video; the original slide deck's results do not transfer automatically. Retain source behavior and author intent when changing masters, grouping or reading order.

Source: [Section508.gov accessible presentations](https://www.section508.gov/create/presentations/). Follow the current guide for application-specific controls.
