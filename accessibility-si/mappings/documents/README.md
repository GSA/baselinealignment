# Documents coverage

The [Document Baseline inventory](baseline.yaml) accounts for every numbered procedure in Version 1.0 and retained not-applicable categories. It links the official procedure, authored checklist, applicable criteria, disposition and evidence/case status. It covers Word, Excel, PowerPoint and PDF through separate format references.

Section 508 non-web exceptions for 2.4.1, 2.4.5, 3.2.3 and 3.2.4 remain explicit. Parsing is no-test-required; some retained categories and CAPTCHA are not applicable, and the AA audio-description test addresses the less strict Level A alternative without a separate outcome. WCAG 2.1/2.2 additions have no Baseline procedure mapping and use supplemental guidance with WCAG2ICT interpretation.

No document Framework cases are supplied by the pinned repository snapshot. Instruction coverage is authored draft; human review, execution and representative document case creation remain separate work. Do not invent published validation evidence.
