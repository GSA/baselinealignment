descr: |
  When a keyboard-accessible method is provided to bypass repeated content, the bypass method must be functional. Specifically, the page includes a “Skip to main content” button before the repeated navigation and search area, but the provided button does not include a direct target or inline activation behavior that would move focus past the repeated content to the main content.

  The code sample includes an apparent keyboard-accessible bypass method that is not functional. A successful test should identify a failure against Baseline 4.A Bypass Blocks.

| **4.A-3** | Use the keyboard to activate the bypass method and verify the functionality of the bypass function. |  |
