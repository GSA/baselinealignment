descr: |
  Short sound or audible cue notifications must have a text alternative that describes the purpose of the sound. Specifically, when the First name or Last name field is empty, the script plays an alert-bell chime and updates the live region with “404 Error,” which does not explain that the form fields are incomplete or describe the purpose of the audible cue.

  The code sample includes an audible cue notification with an insufficient text alternative. A successful test should identify a failure against Baseline 7.C Audible Cues.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-7.C** | Identify any short sound/audible cue that serves as a notification to the user, such as a beep that signifies an error has occurred or a chime to indicate an incoming message. |  |
| **7.C-1** | Check that a text alternative that describes the purpose of the sound is provided with the audible cue. [SC 1.1.1] For example: * A short beep and an asterisk appears on a required field to notify the user that the field must be completed. * As a timer counts down, a bell rings and a "Two minutes left!" message appears on screen. |  |
| **Result** | If any of the above checks fail, then Baseline Test 7.C-AudibleCues fails. |  |
