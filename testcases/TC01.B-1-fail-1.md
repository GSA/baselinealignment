standard-ref: 2.1.2
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/no-keyboard-trap
descr: |
  Components that receive keyboard focus must allow focus to be moved away without disrupting keyboard navigation. Specifically, the script prevents the default action for all keydown events on the State field in the Shipping Address form, which prevents keyboard users from tabbing away from that field to reach the Payment Information form fields.

  The code sample includes a form field that creates a keyboard trap and prevents keyboard users from continuing to later form fields. A successful test should identify a failure against Baseline 1.B No Keyboard Trap.
