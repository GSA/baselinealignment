descr: |
  Images must have appropriate text alternatives based on whether they are meaningful or decorative. Specifically, the GSA logo image is presented as meaningful content but does not include an alt attribute or another text alternative.

  The code sample includes a meaningful image without a text alternative. A successful test should identify a failure against Baseline 6.B Decorative Images.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-6.B** | Identify any image (i.e., img element, or element with role="img", or element that includes a CSS background image) that has an empty text alternative. |  |
| **6.B-1** | Check that the empty text alternative has been programmatically assigned using one of the following techniques [SC 1.1.1]: * Note: If the image does not have any of these attributes, this would be a failure. |  |
| **6.B-1.a** | The ARIA role is “presentation”. |  |
| **6.B-1.b** | The ARIA role is “none”. |  |
| **6.B-1.c** | The aria-hidden is set to “true”. |  |
| **6.B-1.d** | The attribute alt="". |  |
| **6.B-1.e** | The image is inserted via CSS (e.g., using a background image). |  |
| **6.B-2** | Check that none of the following is true [SC 1.1.1]: |  |
| **6.B-2.a** | The image is the only way to convey meaningful information. |  |
| **6.B-2.b** | The image is in the tab order. |  |
| **6.B-2.c** | The image is a functional image that initiates action. |  |
| **6.B-3** | For images with role="presentation" or role="none", check that there are no non-empty text alternative attributes. The presence of such attributes may cause assistive technology to not ignore the image, i.e., provide the image's text alternative to the user. [SC 1.1.1] * Fail Example 1: <img role="none" alt="use your notes"> * Fail Example 2: <img aria-label="turtle" role="presentation"> |  |
| **Result** | If any of the above checks fail, then Baseline Test 6.B-DecorativeImage fails. |  |
