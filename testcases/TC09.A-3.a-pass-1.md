descr: |
  Content must not flash more than three times in any one-second period unless it is below the applicable flash threshold. Specifically, the flash box animation uses a 1-second cycle, producing approximately 1 flash per second, and the animation is off by default until the user activates the Start animation button.

  The code sample includes user-activated flashing content that flashes at or below 3 Hz. A successful test should identify a pass against Baseline 9.A Three Flashes or Below Threshold.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-9.A** | Visually identify content that [flashes](https://www.w3.org/TR/WCAG22/#dfn-flashes). |  |
| **9.A-1** | Set the user agent at standard zoom level, e.g. 100% in a browser. |  |
| **9.A-2** | If there is an option to view a larger version the flashing content, such as a full screen mode, test the larger version. If there is an option to loop or repeat the flashing content, test the looping version. |  |
| **9.A-3** | Check that one of the following is true of the flashing content: [SC 2.3.1] |  |
| **9.A-3.a** | The flashing frequency is less than or equal to 3 flashes in any one second (3 Hertz). |  |
| **9.A-3.b** | The flashing frequency is above 3Hertz or cannot be determined, and at least one of the following is true: |  |
| **9.A-3.b.i** | the combined area of flashes occurring concurrently occupies no more than a 341 x 256 pixel rectangle anywhere on the displayed screen area when the content is viewed at 1024 x 768 pixels. |  |
| **9.A-3.b.ii** | the flash does not include "general flashes" (a pair of opposing changes in relative luminance of 10% or more of the maximum relative luminance (1.0) where the relative luminance of the darker image is below 0.80; and where "a pair of opposing changes" is an increase followed by a decrease, or a decrease followed by an increase). |  |
| **9.A-3.b.iii** | the flash does not include any "pair of opposing transitions involving a saturated red" (a pair of opposing transitions where, one transition is either to or from a state with a value R/(R + G + B) that is greater than or equal to 0.8, and the difference between states is more than 0.2 (unitless) in the CIE 1976 UCS chromaticity diagram. [[ISO_9241-391]]). |  |
| **Result** | If all of the above checks fail, then Baseline Test 9.A-Flashes fails. |  |
