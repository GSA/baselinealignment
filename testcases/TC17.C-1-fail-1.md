descr: |
  For media players that play synchronized media and provide volume or program selection controls, audio description controls must be at the same level as those controls. Specifically, the synchronized video includes an audio description track, but the customized Able Player implementation is intended to place the audio description control inside a submenu rather than at the same level as the volume or program selection controls.

  The code sample includes a synchronized media player where audio description controls are not provided at the required control level. A successful test should identify a failure against Baseline 17.C Media Player Audio Description Control Level.
