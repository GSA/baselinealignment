descr: |
  A page within a set of web pages must be locatable in more than one way unless an exception applies. Specifically, the About page is linked only from the navigation menu, and the code does not provide another locating method such as a site map, search, table of contents, navigation tree, or alternate contextual link.

  The code sample includes a related web page that can be located through only one method. A successful test should identify a failure against Baseline 23.A Related Web Pages.
