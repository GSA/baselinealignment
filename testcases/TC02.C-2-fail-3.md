descr: |
  Keyboard focus must not initiate an unexpected change of context when an interface component receives focus. Specifically, the page includes form fields and a hidden side navigation region, and the scripted behavior moves focus unexpectedly to another component when focus is placed on an interface component.

  The code sample includes an interface component that unexpectedly moves focus to another component when it receives keyboard focus. A successful test should identify a failure against Baseline 2.C On Focus.
