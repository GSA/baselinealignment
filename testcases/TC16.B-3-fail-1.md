descr: |
  A text or audio alternative for prerecorded video-only content must describe all meaningful visual information. Specifically, the video is presented as part of a veggie soup recipe, but the provided text description only says “Take the carrots and cut them,” omitting meaningful visual details such as the number of carrots and the slice size.

  The code sample includes a video-only recipe demonstration with an incomplete text description. A successful test should identify a failure against Baseline 16.B Video-only (Prerecorded).

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-16.B** | Pre-recorded video-only content. Do not include media that is clearly labeled as a media alternative for text. |  |
| **16.B-1** | Check that all video-only content information is also available through a text alternative (e.g., text that provides description of video content and actions) or an audio track that describes the video content. [SC 1.2.1] |  |
| **16.B-2** | View the video-only content while referring to the alternative. |  |
| **16.B-3** | Check that the information in the alternative includes the same information that the video-only presentation displays (e.g., if the video includes multiple characters, the alternative must identify which character is associated with each depicted action). [SC 1.2.1] |  |
| **Result** | If any of the above checks fail, then Baseline Test 16.B-VideoOnlyAlt fails. |  |
