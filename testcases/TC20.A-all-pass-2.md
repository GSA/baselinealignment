descr: |
  A conforming alternate version must be reachable from the non-conforming version through an accessibility-supported mechanism. Specifically, the standard version includes a native button labeled “Switch to Accessible Version” that toggles to an alternate version containing the same suggested search engine links in an ordered list.

  The code sample includes an accessibility-supported mechanism for reaching the alternate version from the standard version. A successful test should identify a pass against Baseline 20.A Conforming Alternate Version.
