descr: |
  When the value of a user control changes through user input, the programmatic value must remain accurate after the change. Specifically, when a user types in the Customer Name field, the script immediately overwrites the input value with “Noah” and stores the user-entered value in a hidden div instead of preserving it in the control.

  The code sample includes a text input whose value is changed incorrectly after user input. A successful test should identify a failure against Baseline 5.D Control Value.

| **5.D-3** | Check that the value of the user control is correct after the user-initiated change of value. [SC 4.1.2] |  |
| **Result** | If any of the above checks fail, then Baseline Test 5.D-ControlValue fails. |  |
