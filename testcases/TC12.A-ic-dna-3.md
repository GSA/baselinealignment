  This test applies to data tables where table roles and relationships are needed to understand the content. Specifically, the table is used to lay out independent “Fast Facts” text blocks, and the cell-to-header relationship is not needed to understand the content.

  The code sample includes a layout table where tabular relationships are not necessary to understand the content. A successful test should determine that Baseline 12.A Data Table Roles does not apply.
