  This test applies to moving, blinking, or scrolling content that starts automatically and lasts long enough to require a pause, stop, or hide mechanism. Specifically, the page presents a static image of Marines raising the flag and a play-button overlay, and the animation is started only when the user activates the button.

  The code sample includes moving image content that requires user activation before it starts. A successful test should determine that Baseline 21.B Moving Information does not apply.
