descr: |
  Form field accessible names and descriptions must include relevant instructions and cues needed to complete the field. Specifically, the visible label provides the required date format, but the date input has aria-label="Form Field 1", which does not include the date-of-birth purpose, required status, or DD/MM/YYYY format instruction.

  The code sample includes a date field whose accessible name does not provide the relevant instructions and cues. A successful test should identify a failure against Baseline 10.A Form Names.
result: Fail
