descr: |
  Form fields must have an accessible name and description that describe the field’s purpose. Specifically, the username input is visually labeled “Username,” but the input has aria-label="Form Field 1", which overrides the visible label with a non-descriptive accessible name.

  The code sample includes a username field whose accessible name does not describe the field’s purpose. A successful test should identify a failure against Baseline 10.A Form Names.
