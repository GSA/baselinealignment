descr: |
  A conforming alternate version must control access to any non-conforming version so that both versions can only be reached from a conforming version. Specifically, the page is labeled “Conforming Version” and provides links to both the conforming version and the non-conforming version from that conforming page.

  The code sample includes a conforming page that provides the available paths to the conforming and non-conforming versions. A successful test should identify a pass against Baseline 20.A Conforming Alternate Version.
