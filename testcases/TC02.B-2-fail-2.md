title: Focus - order does not preserve the usability
tcid: TC02.B-2-fail-2
tc-version: ""
baseline-version: "3.1"
standard: WCAG
standard-ref: 2.4.3
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/focus-order
descr: |
  The focus order of keyboard-accessible interface components must preserve the meaning and usability of the page. Specifically, the Account Options menu items are visually ordered as Profile, Settings, Billing, Notifications, and Sign out, but positive tabindex values create a keyboard focus order of Sign out, Profile, Notifications, Settings, and Billing.

  The code sample includes a revealed menu where all items are reachable, but the focus order does not preserve usability. A successful test should identify a failure against Baseline 2.B Focus Order.
result: Fail
