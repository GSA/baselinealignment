descr: |
  Visually apparent headings must be programmatically identified with heading levels that match the visual heading structure. Specifically, the page uses native heading elements such as h1, h2, and h3, but also assigns conflicting aria-level values, including aria-level="3" on the main page title and aria-level="2" on a subsection heading.

  The code sample includes visually apparent headings with conflicting native and ARIA heading levels. A successful test should identify a failure against Baseline 13.B Visual Headings Programmatic.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-13.B** | Visually apparent headings, which denote sections of content. Headings are often in a larger, bolded font separated from paragraphs by extra spacing (though not always). Note the hierarchy and structure of each heading with respect to other headings on the page. |  |
| **13.B-1** | Check that all visual headings are programmatically determinable and that programmatic heading levels logically match the visual heading presentation within the heading structure [SC 1.3.1]: |  |
| **13.B-1.a** | The most important heading(s) should have the highest priority level. For example, <h1> is a higher level than <h2>, which is higher than <h3>. |  |
| **13.B-1.b** | Headings with an equal or higher level start a new section; headings with a lower level start new subsections that are part of the higher leveled section. |  |
| **13.B-1.c** | HTML or ARIA programmatically identify each heading. When both are used, heading levels must match. * H42: each heading is marked with <h1> to <h6>. * ARIA12: each heading is marked with role="heading" and aria-level="#". The default heading level is “2” when none is specified. |  |
| **13.B-1.c.i** | [H42](H42: each heading is marked with <h1> to <h6>.): each heading is marked with <h1> to <h6>. |  |
| **13.B-1.c.ii** | [ARIA12](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA12): each heading is marked with role="heading" and aria-level="#". |  |
| **13.B-1.c.iii** | When both techniques are used, ARIA takes precedence and the heading level is indicated by aria-level. |  |
| **Result** | If the above check fails, then Baseline Test 13.B-VisHeadingProg fails. |  |
