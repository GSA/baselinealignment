descr: |
  Captions for prerecorded synchronized media must include meaningful sound effects and other meaningful audio needed to understand the program content. Specifically, the video references an English captions file, but the intended failure is that the captions do not include meaningful sound effects from the start-stop video.

  The code sample includes prerecorded synchronized media with captions that omit meaningful non-speech audio. A successful test should identify a failure against Baseline 17.D Captions (Prerecorded).

|------------------|--------------------|---------------------------|
| **IC-17.D** | Pre-recorded synchronized multimedia. Do not include media that is clearly labeled as a media alternative for text. |  |
| **17.D-1** | Enable captions through multimedia player functions and play the media. If a separate media file with captions is provided, test that file. |  |
| **17.D-2** | Check that captions are provided. |  |
| **17.D-3** | Check that captions are accurate and include all dialogue and equivalents for non-dialogue audio information needed to understand the program content, including sound effects, music, laughter, speaker identification and location. [SC 1.2.2] |  |
| **17.D-3.a** | Listen to the audio of the entire synchronized media. |  |
| **17.D-3.b** | Compare the audio to the captions for accuracy, time-synchronization, and equivalence. |  |
| **Result** | If any of the above checks fail, then Baseline 17.D-CaptionsPrerecorded fails. |  |
