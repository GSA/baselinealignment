descr: |
  Forms that cause financial transactions must allow the user to review and confirm the transaction before final submission. Specifically, selecting Order Now hides the order form and displays an order summary with the number of pizzas, delivery time, convenience fee, and total charge, along with buttons to Modify Order or Confirm Order and Pay.

  The code sample includes a pizza order form that presents a review step and requires confirmation before charging the credit card on file. A successful test should identify a pass against Baseline 10.G Error Prevention (Legal, Financial, Data).
