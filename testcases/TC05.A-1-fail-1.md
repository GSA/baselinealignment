descr: |
  The combination of the accessible name and accessible description for each user control must not be empty. Specifically, the menu toggle button has no visible text, no aria-label, no aria-labelledby, and no other apparent source for an accessible name or description.

  The code sample includes a user control with an empty accessible name and description. A successful test should identify a failure against Baseline 5.A Control Name.
