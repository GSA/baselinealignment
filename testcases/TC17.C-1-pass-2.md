descr: |
  For media players that play synchronized media and provide volume controls, audio description controls must be at the same level as the volume controls. Specifically, the synchronized video includes an audio description track and uses a customized Able Player script intended to expose the audio description control at the same level as the volume controls.

  The code sample includes a synchronized media player with audio description controls at the same level as volume controls. A successful test should identify a pass against Baseline 17.C Media Player Audio Description Control Level.
