descr: |
  Color must not be the only visual means used to convey information, indicate an action, prompt a response, or identify required information. Specifically, the page note says fields in red text are required, and the First name and Last name labels are distinguished as required only through the required class without an on-screen non-color indicator such as an asterisk.

  The code sample includes required form fields identified only by red text. A successful test should identify a failure against Baseline 7.A Use of Color.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-7.A** | Content that uses color to convey meaning, indicate an action, prompt a response, distinguish a visual element, or identify errors. Exclude colors of links that indicate visited or unvisited. |  |
| **7.A-1** | Check if one or more of the following is true: |  |
| **7.A-1.a** | The content using color to convey meaning also provides on-screen alternate text describing the color and/or the meaning conveyed by the color when the user must be able to accurately perceive or differentiate a particular color. [SC 1.4.1] |  |
| **7.A-1.b** | The content using color to convey meaning also provides other visual differentiation (e.g., shape, position, size, underline) with a clear indication of its meaning when the user must be able to accurately perceive or differentiate a particular color. [SC 1.4.1] |  |
| **7.A-1.c** | The content using only a difference in colors to convey meaning uses colors (hues) that have a contrast ratio of 3:1 or greater. This content does not require the user to be able to accurately perceive or differentiate a particular color. [SC 1.4.1] |  |
| **Result** | If BOTH of the above checks fail, then Baseline Test 7.A-Color fails. |  |
