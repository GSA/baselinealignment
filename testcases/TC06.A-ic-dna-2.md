  This test applies to images that require a non-empty text alternative. Specifically, the image is presented as a decorative frame and has an empty alt attribute, indicating that it is intended to be ignored by assistive technologies.

  The code sample includes a decorative image with an empty text alternative. A successful test should determine that Baseline 6.A Meaningful Images does not apply.
