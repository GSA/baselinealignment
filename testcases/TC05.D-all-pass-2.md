descr: |
  When the value of a user control changes through user input, the programmatic value must remain accurate after the change. Specifically, the Customer Name input allows the user-entered value to remain in the native text field, and the script does not overwrite or conflict with the control’s value.

  The code sample includes a text input whose value remains accurate after user input. A successful test should identify a pass against Baseline 5.D Control Value.
