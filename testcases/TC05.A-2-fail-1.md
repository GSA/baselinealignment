standard: WCAG

descr: |
  The non-empty combination of the accessible name and accessible description for each user control must describe the control’s purpose. Specifically, the menu toggle button has an accessible name of “Move up,” but the control’s actual purpose is to expand or collapse the list of menu items.

  The code sample includes a user control with a non-empty accessible name that does not describe the control’s purpose. A successful test should identify a failure against Baseline 5.A Control Name.
