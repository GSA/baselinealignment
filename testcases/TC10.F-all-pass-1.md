descr: |
  When an input error is automatically detected and suggestions for correction are known, the error notification must provide a suggestion for fixing the error. Specifically, the date field is labeled as requiring MM/DD/YYYY format, and when submitDateForm() detects an incorrectly formatted date, it updates the live region with “Error: Date must be in the format of MM/DD/YYYY.”

  The code sample includes a date field with automatic validation that provides a suggestion for correcting the date format. A successful test should identify a pass against Baseline 10.F Error Suggestion.
