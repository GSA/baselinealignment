descr: |
  This test applies when the non-conforming version can only be reached from the conforming version. Specifically, the page provides separate links to both the accessible version and the non-conforming version from the same page.

  The code sample includes a non-conforming version that can be reached from another page rather than only from the conforming version. A successful test should determine that Baseline 20.A Conforming Alternate Version does not apply.
