descr: |
  Instructions must not rely solely on visual location to identify controls or explain how to operate them. Specifically, the heading tells users to select the button on the bottom left to go to the next page and the button on the bottom right to go back, while the buttons do not include visible text identifying “Next” or “Back.”

  The code sample includes navigation instructions that rely solely on the visual location of buttons. A successful test should identify a failure against Baseline 7.B Sensory Characteristics.

| **IC-7.B** | Identify instructions for understanding and operating content that use sensory information to convey information. This may include references to shape, size, visual location, orientation, or sound. |  |

[SC 1.3.3] For example: * To see your changes, select the round button labeled “Go”. * The links on the right, with the heading “Resources”, provide further information. * Select the lower-right “Cancel” button to close this session. |  |
