descr: |
  This test applies when a conforming alternate version provides all of the same information as the non-conforming version. Specifically, the standard version includes location hours, but the alternate version lists only the locations and sub-locations without the same hours information.

  The code sample includes an alternate version that does not provide all of the same information as the standard version. A successful test should determine that Baseline 20.A Conforming Alternate Version does not apply.
