descr: |
  When prerecorded audio is provided as a media alternative for text, all meaningful audible information must be available in the text. Specifically, the written instructions only say to take some carrots and slice them, while the audio alternative is intended to provide more specific information about the number of carrots and slice size.

  The code sample includes a prerecorded audio alternative where not all meaningful audible information is available in the text. A successful test should identify a failure against Baseline 16.C Audio Media Alternative (Prerecorded).

| **16.C-1** | Identify the text for which the media is an alternative. |  |
| **16.C-2** | Play the media that is labeled as an equivalent alternative for the text. |  |

| **Result** | If any of the above checks fail, then the audio-only is not a media alternative for text. Perform Baseline Test 16.A Test Procedure for Audio-Only (Prerecorded). |  |
