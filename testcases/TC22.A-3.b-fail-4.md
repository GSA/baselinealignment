descr: |
  When text is resized to at least 200 percent, text entered in text-based form controls must also resize fully. Specifically, the form labels and page text use fixed text sizing, while the text inputs use font-size: 2vh, which is intended not to resize consistently with the rest of the page text.

  The code sample includes text-based form controls where entered text is intended not to resize fully with the page. A successful test should identify a failure against Baseline 22.A Resize Text.
