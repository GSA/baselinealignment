descr: |
  If non-standard keyboard commands are required to move focus away from a component or set of components, the user must be informed of the command and the command must work. Specifically, focus is trapped between the Full Name and Email fields in the Contact Information section, and although the page instructs users to press Ctrl + Alt + X to move to the Mailing Address section, no script is provided to make that command move focus out of the trap.

  The code sample includes a keyboard trap with an on-screen instruction for a non-standard keyboard command that does not work. A successful test should identify a failure against Baseline 1.B No Keyboard Trap.
