descr: |
  The purpose of each link must be determinable from the link text alone or from its programmatically determinable context. Specifically, each document download link has short link text such as “PDF,” “CSV,” “JSON,” “XLSX,” or “DOCX,” and each link appears within a list item that provides the full document title.

  The code sample includes document download links whose purposes are determinable from their list item context. A successful test should identify a pass against Baseline 14.A Link Purpose (In Context).
