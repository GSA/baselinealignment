descr: |
  Keyboard-accessible interface components must provide a visible indication of focus when they receive keyboard focus, and the focus indicator must remain visible while focus remains on the component. Specifically, the text fields and radio buttons are native keyboard-accessible controls, and no CSS or scripting is included that removes or time-limits the visible focus indicator.

  The code sample includes keyboard-accessible form controls that provide a visible indication of focus with no time limit. A successful test should identify a pass against Baseline 2.A Focus Visible.
