descr: |
  Components that receive keyboard focus must allow focus to be moved away without disrupting keyboard navigation. Specifically, the script intercepts Tab and Shift+Tab on the first and last links in the keyboard-trap group and moves focus back within that group, preventing keyboard access to the “Link cannot be accessed” and “Another link that cannot be accessed” links.

  The code sample includes keyboard focusable links where focus loops between the first three links and prevents keyboard users from reaching later links on the page. A successful test should identify a failure against Baseline 1.B No Keyboard Trap.
