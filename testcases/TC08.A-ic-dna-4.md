descr: |
  Minimum text contrast requirements do not apply to text that is part of a picture with significant other visual content. Specifically, the code sample includes a Times Square image with traffic, billboards, people, buildings, and other visual content where any sign text is part of the broader scene.

  The code sample includes text contained within a larger photographic image with significant visual content. A successful test should determine that Baseline 8.A Contrast (minimum) does not apply.
