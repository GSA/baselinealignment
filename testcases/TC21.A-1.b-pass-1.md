descr: |
  When content has a time limit, users must be able to adjust the time limit before encountering it to at least 10 times the default length. Specifically, the default time limit is 30 seconds, and the page provides a number input that allows users to set the time limit up to 300 seconds before starting the timed activity.

  The code sample includes a timed activity with a control that adjusts the time limit before it begins to 10 times the default duration. A successful test should identify a pass against Baseline 21.A Timing Adjustable.
