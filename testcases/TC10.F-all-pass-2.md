descr: |
  When an input error is automatically detected and suggestions for correction are known, the user must be given useful guidance for correcting the error. Specifically, the script detects when Caps Lock is turned on and updates the live region with “Warning: CAPS LOCK turned on,” and it also provides targeted messages when the username or password contains uppercase characters or when either required field is empty.

  The code sample includes username and password fields with automatic error guidance for capitalization and missing required values. A successful test should identify a pass against Baseline 10.F Error Suggestion.
