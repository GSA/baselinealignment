descr: |
  Keyboard focus must not initiate an unexpected change of context when an interface component receives focus. Specifically, the link, form fields, help buttons, and submit button do not submit a form, open a new window, or move focus to another component merely by receiving focus.

  The code sample includes interface components that do not initiate an unexpected change of context when they receive keyboard focus. A successful test should identify a pass against Baseline 2.C On Focus.
