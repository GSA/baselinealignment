descr: |
  Prerecorded audio-only content must have a text alternative that provides equivalent information, including meaningful non-speech audio. Specifically, the page provides a transcript of the spoken conversation between Lauren and Paul, but the transcript does not include other meaningful audible content from the train-conversation audio.

  The code sample includes prerecorded audio with a transcript that does not include all meaningful audible information. A successful test should identify a failure against Baseline 16.A Audio-only (Prerecorded).

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-16.A** | Pre-recorded audio-only content. Do not include media that is clearly labeled as a media alternative for text. |  |
| **16.A-1** | Check that the content provides transcript(s) for audio-only content. [SC 1.2.1] |  |
| **16.A-2** | Check that the transcript is text (e.g., an image-only PDF would not be sufficient to pass this test). [SC 1.2.1] |  |
| **16.A-3** | Play the audio-only content entirely while referring to the alternative. |  |
| **16.A-4** | Check that the information in the transcript is an accurate and complete representation of the audio-only content and includes relevant sounds in addition to dialogue, such as doors banging, sirens wailing, identification of speakers in dialogue, etc. [SC 1.2.1] |  |
| **Result** | If any of the above checks fail, then Baseline Test 16.A-AudioOnlyTranscript fails. |  |
