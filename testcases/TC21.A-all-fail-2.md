title: Timed Events - the user can extend the time limit, but only a maximum of 9 times
tcid: TC21.A-all-fail-2
tc-version: "1"
baseline-version: "3.1"
standard: WCAG
standard-ref: 2.2.1
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/timing-adjustable
descr: |
  When content has a time limit and users are allowed to extend it, the mechanism must allow at least 10 extensions. Specifically, the purchase confirmation page provides an “Extend Time Limit” button, but the script limits the user to fewer than 10 extensions before displaying a maximum-extension alert.

  The code sample includes a timed purchase confirmation page where the time limit cannot be extended at least 10 times. A successful test should identify a failure against Baseline 21.A Timing Adjustable.
result: Fail

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-21.A** | Identify any instances of content time limits (excluding exceptions described above). |  |
| **21.A-1** | Check that at least one of the following is true before time expires [SC 2.2.1]: |  |
| **21.A-1.a** | The user has the ability to turn off the time limit. |  |
| **21.A-1.b** | The user has the ability to adjust the time limit before encountering it over a wide range that is at least ten times the length of the default setting. |  |
| **21.A-1.c** | The user is warned before time expires AND: |  |
| **21.A-1.c.i** | Given at least 20 seconds to extend the time limit with a simple action (e.g., “press the space bar”), AND |  |
| **21.A-1.c.ii** | Allowed to extend the time limit at least ten times. |  |
| **Result** | If the above check fails, then Baseline Test 21.A-TimingAdjustable fails. |  |
