descr: |
  When a user control changes through use of the application, its role must remain valid and appropriate after the change. Specifically, the Submit button has role="toggle-button", which is not a valid ARIA role, and the script changes the button from disabled to enabled when the required fields are completed.

  The code sample includes a user control whose role is invalid when the control becomes available through application use. A successful test should identify a failure against Baseline 5.B Control Role.
