descr: |
  Keyboard-accessible interface components must provide a visible indication of focus when they receive keyboard focus, and the focus indicator must remain visible while focus remains on the component. Specifically, the first name field, last name field, and submit button call hideFocus(this) when they receive focus, causing the visible focus indication to be removed while the component still has programmatic focus.

  The code sample includes keyboard-accessible form controls with a visible focus indicator that is time limited. A successful test should identify a failure against Baseline 2.A Focus Visible.
