standard: WCAG
standard-ref: 2.4.2

descr: |
  HTML documents must have a title that describes the page and distinguishes it from other pages in the same set of web pages. Specifically, both the About Us page and the Homepage use the same title, “Test Case 11.A-2,” even though their visible page headings and content identify different pages.

  The code sample includes multiple pages in a set that use the same page title for different content. A successful test should identify a failure against Baseline 11.A Page Titled.
