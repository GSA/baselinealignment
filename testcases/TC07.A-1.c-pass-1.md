descr: |
  Color must not be the only visual means used to convey meaning unless the color difference provides sufficient contrast so users do not need to accurately perceive or distinguish a particular color. Specifically, the restaurant names “Pete’s Pizza,” “Bonnie’s Burritos,” and “Isaac’s Ice Cream” are marked with the restaurant class, and the intended pass condition depends on those names having a color difference with a contrast ratio of at least 3:1 against the surrounding paragraph text.

  The code sample includes restaurant names visually distinguished from surrounding text by color. A successful test should identify a pass against Baseline 7.A Use of Color.
