descr: |
  Text must be capable of being resized to at least 200 percent using an available resizing mechanism. Specifically, the page provides Text Size Controls with buttons that call changeTextSize() to increase or decrease the body font size, and the article text is contained in normal HTML headings and paragraphs.

  The code sample includes on-page controls for increasing and decreasing text size. A successful test should identify a pass against Baseline 22.A Resize Text.
