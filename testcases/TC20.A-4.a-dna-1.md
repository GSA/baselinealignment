descr: |
  This test applies when the conforming alternate version can be reached from the non-conforming version through an accessibility-supported mechanism. Specifically, the page provides a “Switch to Accessible Version” button, but the button has tabindex="-1", removing it from the keyboard focus order.

  The code sample includes a mechanism for reaching the alternate version that is not keyboard accessible. A successful test should determine that Baseline 20.A Conforming Alternate Version does not apply.
