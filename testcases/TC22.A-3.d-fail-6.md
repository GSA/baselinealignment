descr: |
  When text is resized to at least 200 percent, content must remain available. Specifically, the page includes navigation items for Home, About, Articles, and Contact, but the media query hides the navbar when the layout reaches the specified width condition associated with enlarged text or reduced viewport space.

  The code sample includes navigation content that becomes unavailable when the page is resized. A successful test should identify a failure against Baseline 22.A Resize Text.
