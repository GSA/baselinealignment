descr: |
  When keyboard users activate a control that reveals hidden focusable content, the revealed focusable content must be included in the focus order. Specifically, activating the Help button reveals a side navigation panel with a close button and links, but the focus order continues through the remaining form fields and submit button before reaching the revealed side navigation content.

  The code sample includes revealed focusable content that is not included in the focus order at the point where it is revealed. A successful test should identify a failure against Baseline 2.A Focus Visible.
