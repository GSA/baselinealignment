  A page within a set of web pages must be locatable in more than one way unless an exception applies. Specifically, the Home, About, and Contact pages can be reached through the top navigation menu, and the same pages are also listed in a Site Map.

  The code sample includes a set of related web pages that can be located using both navigation links and a site map. A successful test should identify a pass against Baseline 23.A Related Web Pages.
