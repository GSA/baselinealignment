descr: |
  Images of text must be customizable when customization is required for the text presentation. Specifically, the announcement text is rendered on a canvas as an image of text, and the page provides controls to change the font family, text size, and background color, but the text color remains fixed and cannot be customized.

  The code sample includes an image of text whose text color cannot be customized as text. A successful test should identify a failure against Baseline 6.D Images of Text.
