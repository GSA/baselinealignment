descr: |
  When an input error is automatically detected and suggestions for correction are known, the error notification must provide a suggestion for fixing the error. Specifically, the First name and Last name fields are required, and when submitForm() detects missing values on this fail page, it updates the live region with only “Form error.”

  The code sample includes required form fields where the error message does not suggest completing the missing required fields. A successful test should identify a failure against Baseline 10.F Error Suggestion.
