title: Forms - form that adds user-controllable data in storage system is not reversible, checked, nor confirmed
tcid: TC10.G-all-fail-1
tc-version: "1"
baseline-version: "3.1"
standard: WCAG
standard-ref: 3.3.4
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/error-prevention-legal-financial-data
descr: |
  The page has a form, which contains two select boxes and a submit button. Changing the selection in the select boxes causes no screen change and triggers no validation. When the submit button is pressed, the form disappears, a confirmation notification appears and receives focus. The notification message says that an irreversible financial transaction has occurred. The system did not give the user a mechanism to review, confirm, or correct information before the submission. The system does not provide an opportunity to correct input errors. The system provides no way to reverse the submission. A successful test should identify a FAIL against Baseline 10.G Error Prevention (Legal, Financial, Data).
result: Fail

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-10.G** | Page that causes legal commitments or financial transactions for the user to occur, that modify or delete user-controllable data in data storage systems, or that submit user test responses. |  |
| **10.G-1** | Complete the form components necessary to submit. Include errors. |  |
| **10.G-2** | Check that at least one of the following is true [SC 3.3.4]: |  |
| **10.G-2.a** | Reversible: Submissions are reversible. |  |
| **10.G-2.b** | Checked: Data entered by the user is checked for input errors and the user is provided an opportunity to correct them. |  |
| **10.G-2.c** | Confirmed: A mechanism is available for reviewing, confirming, and correcting information before finalizing the submission. |  |
| **Result** | If any of the above checks fail, then Baseline Test 10.G-ErrorPrevention fails. |  |
