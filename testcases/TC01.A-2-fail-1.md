descr: |
    All functionality available by mouse must also be available by keyboard, and individual keystrokes must not require specific timing for activation. Specifically, the Request Password Reset button can be reached by keyboard, but changing it to Request User Name requires the user to press and hold the Spacebar for three seconds before releasing it.

    The code sample includes a keyboard-operable button function that requires a timed keypress and does not provide an alternative control without the timing requirement. A successful test should identify a failure against Baseline 1.A Keyboard Access.
