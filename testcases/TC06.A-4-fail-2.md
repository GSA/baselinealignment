descr: |
  Images that require a non-empty text alternative must have an accessible name or description that provides an equivalent purpose or information, and any longer description used to explain the image must be programmatically associated with the image. Specifically, the scatter plot image has a brief alt value, while the more detailed description appears in surrounding page text and is not programmatically associated with the image.

  The code sample includes a meaningful graph image with a vague text alternative and a longer nearby description that is not programmatically associated with the image. A successful test should identify a failure against Baseline 6.A Meaningful Images.
result: Fail

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-6.A** | Identify any image (i.e., img element or an element with role="img") that has a non-empty text alternative (combination of the accessible name and accessible description) per the [HTML Accessibility API Mappings 1.0 for img](https://www.w3.org/TR/html-aam-1.0/#img-element-accessible-name-computation). |  |
| **6.A-1** | Check that none of the following is true [SC 1.1.1]: |  |
| **6.A-1.a** | The image is page design/formatting and could be ignored by assistive technology without any loss of meaning. |  |
| **6.A-1.b** | The image is not visible on the page. |  |
| **6.A-2** | Check that the ARIA role is NOT "presentation".[SC 4.1.2] |  |
| **6.A-3** | Check that the ARIA role is NOT “none”. [SC 4.1.2] |  |
| **6.A-4** | Check that the non-empty text alternative (combination of accessible name and accessible description) provides an equivalent description of the image's purpose. [SC 1.1.1] |  |
| **Result** | If any of the above checks fail, then Baseline Test 6.A-MeaningfulImage fails. |  |
