descr: |
  All functionality that is available by mouse must also be available by keyboard, and individual keystrokes must not require specific timing for activation. Specifically, the first name, last name, email sign-up checkbox, and email form field are native keyboard-accessible controls and do not include scripting, tabindex values, or timing requirements that prevent keyboard operation.

  The code sample includes form controls that can be accessed and operated using the keyboard, and no functionality requires specific timing of individual keystrokes. A successful test should identify a pass against Baseline 1.A Keyboard Access.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-1.A** | All functionality of the content that is available by mouse control must be keyboard accessible. Determine the functionality of visible and hidden interactive interface components (links, form fields, drop down menus, show/hide content, tree views, pop ups/light boxes, iframes, etc.) available using a mouse (hover and/or click). |  |
| **1.A-1** | Check that all functionality can be accessed and executed using only the keyboard. [SC 2.1.1] |  |
| **1.A-1.a** | Use the keyboard to perform functions available by mouse (including drop-down menus, form fields, revealing/hiding content, tooltips, AND all interactive interface components). |  |
| **1.A-1.a.i** | If an interactive interface component is not available by keyboard, check if another control is provided on the page with the same functionality which is available by keyboard. (All functionality must meet this requirement.) |  |
| **1.A-2** | Check that individual keystrokes do not require specific timings for activation.[SC 2.1.1] |  |
| **1.A-2.a** | If operation requires specific timings of individual keystrokes, check if another control is provided on the page with the same functionality which does not require specific timings for operation. (All functionality must be available without requiring specific timings for individual keystrokes to operate.) |  |
| **Result** | If any of the above checks fail, then Baseline Test 1.A-KeyboardAccess fails. |  |
