descr: |
  When CSS positioning is removed, the meaning of the content in context must remain correct. Specifically, the CSS positions “Animals” and “States” as separate column headings, but the source order places the animal items and state items in an order that does not preserve their visual grouping without positioning.

  The code sample includes CSS-positioned content where the relationships between headings and items are not preserved without CSS positioning. A successful test should identify a failure against Baseline 18.B CSS Positioned Content.
