descr: |
  When prerecorded video-only content is provided as a media alternative for text, all meaningful visual information in the media must also be available in the text. Specifically, the video is labeled as a video alternative for the recipe text, but the text instruction only says to prepare the veggies and does not include meaningful visual details such as using three carrots and cutting them into quarter-inch slices.

  The code sample includes a video alternative where all meaningful visual information is not available in the text. A successful test should identify a failure against Baseline 16.D Video Media Alternative (Prerecorded).

| **16.D-1** | Identify the text for which the media is an alternative. |  |
