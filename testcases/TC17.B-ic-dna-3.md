descr: |
  This test applies when a synchronized media player has caption controls and volume or program selection controls that establish the required control level. Specifically, the custom video player includes play, rewind, forward, fullscreen, download, and timeline controls, but does not include a volume control in the provided control set.

  The code sample includes a synchronized media player without volume controls for this control-level comparison. A successful test should determine that Baseline 17.B Media Player Caption Control Level does not apply.
