descr: |
  Keyboard focus must not initiate an unexpected change of context when an interface component receives focus, although changes in content are allowed when they do not change context. Specifically, the navigation links and About Us disclosure button are interface components, but the code does not cause a form submission, new window, focus movement, or other change of context merely when a component receives focus.

  The code sample includes an interface component that may initiate a change in content, but does not initiate a change of context on focus. A successful test should identify a pass against Baseline 2.C On Focus.
