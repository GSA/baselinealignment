descr: |
  For media players that play synchronized media and provide program selection controls, caption controls must be at the same level as the program selection controls. Specifically, the video player includes a captions track and is configured so the captions control is available at the same level as program selection controls.

  The code sample includes a synchronized media player with caption controls at the same level as program selection controls. A successful test should identify a pass against Baseline 17.B Media Player Caption Control Level.
