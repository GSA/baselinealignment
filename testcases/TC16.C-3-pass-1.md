descr: |
  When prerecorded audio is provided as a media alternative for text, the meaningful audible information must also be available in the text. Specifically, the written instructions state to take three carrots and cut them into quarter-inch slices, matching the meaningful information provided by the carrot-audio media alternative.

  The code sample includes a prerecorded audio alternative whose meaningful information is available in the text instructions. A successful test should identify a pass against Baseline 16.C Audio Media Alternative (Prerecorded).

|------------------|--------------------|---------------------------|
| **IC-16.C** | Pre-recorded audio-only that is clearly labeled as a media alternative for text. |  |
| **16.C-1** | Identify the text for which the media is an alternative. |  |
| **16.C-2** | Play the media that is labeled as an equivalent alternative for the text. |  |
| **16.C-3** | Check that the meaningful audible information of the media is available in the text. |  |
| **Result** | If any of the above checks fail, then the audio-only is not a media alternative for text. Perform Baseline Test 16.A Test Procedure for Audio-Only (Prerecorded). |  |
