title: Tables - table clearly used purely for layout uses ARIA role=table and other associated ARIA roles in table elements

standard: WCAG
standard-ref: 4.1.2
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/name-role-value
descr: |
  Layout tables must not expose ARIA table semantics when the table is used only for visual layout. Specifically, the table contains unrelated text blocks for page layout, but it uses role="table" along with role="row" and role="cell".

  The code sample includes a layout table that incorrectly exposes ARIA table structure roles. A successful test should identify a failure against Baseline 12.C Layout Tables.
result: Fail
