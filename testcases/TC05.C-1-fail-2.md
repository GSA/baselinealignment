descr: |
  The state of each user control must be programmatically determinable and accurate. Specifically, the email updates checkbox uses aria-disabled="true", but it does not use the native disabled attribute, so the checkbox remains available to users while being reported as disabled.

  The code sample includes a checkbox with an inaccurate disabled state. A successful test should identify a failure against Baseline 5.C Control State.
