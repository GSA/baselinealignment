descr: |
  Auto-updating information must provide a mechanism to pause, stop, hide, or control the frequency of updates unless an exception applies. Specifically, the stock market page provides an “Update prices every minute” button that calls updateRefreshTime(60000, this) to control the refresh interval for the stock price information.

  The code sample includes auto-updating stock information with a control for changing the update frequency. A successful test should identify a pass against Baseline 21.C Auto-updating Information.
