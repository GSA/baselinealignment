descr: |
  Blocks of content that are repeated on multiple pages must have a keyboard-accessible method to bypass the repeated content, and the method must work as intended. Specifically, the page includes a “Skip to main content” button before the repeated navigation and search area, and the main content includes a focusable link that can receive focus after the repeated block is bypassed.

  The code sample includes a keyboard-accessible method that bypasses only the repeated navigation content. A successful test should identify a pass against Baseline 4.A Bypass Blocks.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-4.A** | Blocks of content that are repeated on multiple pages, including navigation links, page headers, and banners. |  |
| **4.A-1** | Use standard keyboard commands to navigate forward to repetitive blocks of content. Some bypass functions may not be visible until they receive focus. |  |
| **4.A-2** | Check that a keyboard-accessible method is provided to bypass repetitive content. [SC 2.4.1] |  |
| **4.A-3** | Use the keyboard to activate the bypass method and verify the functionality of the bypass function. |  |
| **4.A-4** | Check that the method works as intended. [SC 2.4.1] For example: * The block of repeated content is hidden, closed or skipped. * If the method is intended to skip, check that the focus is shifted past the repetitive content only. Content that is not repetitive should not be skipped. If there is only text/no interactive component to receive the shift of focus, it may not be evident that a focus shift occurred. |  |
| **Result** | If any of the above checks fail, then Baseline Test 4.A-BypassBlocks fails. |  |
