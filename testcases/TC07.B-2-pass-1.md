descr: |
  Instructions or notifications that use sound must also provide programmatically determinable visual or textual cues that convey the same information. Specifically, the form submission script plays the submit-sound audio file and also presents an alert stating “Form submitted successfully!”

  The code sample includes a sound cue for form submission along with a textual confirmation message. A successful test should identify a pass against Baseline 7.B Sensory Characteristics.

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-7.B** | Identify instructions for understanding and operating content that use sensory information to convey information. This may include references to shape, size, visual location, orientation, or sound. |  |
| **7.B-1** | Check that the instructions contain additional information that allows it to be located, identified, and understood without any knowledge of its shape, size, or relative position. [SC 1.3.3] For example: * To see your changes, select the round button labeled “Go”. * The links on the right, with the heading “Resources”, provide further information. * Select the lower-right “Cancel” button to close this session. |  |
| **7.B-2** | Check that any auditory cues also provide programmatically determinable visual and/or textual cues. [SC 1.3.3] For instance, * At the sound of the beep and the appearance of the timer, begin the quiz. |  |
| **Result** | If any of the above checks fail, then Baseline Test 7.B-SensoryCharacteristics fails. |  |
