  This test applies when an alternate version conforms to the applicable accessibility requirements. Specifically, the alternate version presents the suggested search engine list using text styled with the details class, which is intended to fail sufficient color contrast.

  The code sample includes an alternate version that does not meet the applicable accessibility requirements. A successful test should determine that Baseline 20.A Conforming Alternate Version does not apply.
