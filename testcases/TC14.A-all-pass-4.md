descr: |
  The purpose of each link must be determinable from the link text alone or from its programmatically determinable context. Specifically, each row contains a document title in a row header and a “Download” link in the adjacent Download column, allowing the purpose of each download link to be determined from the table structure.

  The code sample includes document download links whose purposes are determinable from the associated row headers and column header. A successful test should identify a pass against Baseline 14.A Link Purpose (In Context).
