descr: |
  All functionality that is available by mouse must also be available using the keyboard alone. Specifically, the City and Area Code text fields can be accessed by mouse, but each has tabindex="-1", which removes those fields from the keyboard tab order, and no alternative keyboard-accessible controls are provided for entering the same information.

  The code sample includes seven form fields where the City and Area Code fields are available by mouse but not available through sequential keyboard navigation. A successful test should identify a failure against Baseline 1.A Keyboard Access.
