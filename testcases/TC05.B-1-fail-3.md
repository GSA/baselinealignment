descr: |
  The role of each user control must be valid and appropriate for the control’s function. Specifically, the Submit button is assigned role="link", which is a valid role but does not match the button’s submit function.

  The code sample includes a user control with a valid role that is not appropriate for its function. A successful test should identify a failure against Baseline 5.B Control Role.
