title: Focus - focus not returned to trigger control
tcid: TC02.B-1.b.i-fail-1
tc-version: "1"
baseline-version: "3.1"
standard: WCAG
standard-ref: 2.4.3
standard-ref-url: https://www.w3.org/WAI/WCAG22/Understanding/focus-order
descr: |
  When keyboard users close or hide revealed content, focus must be returned to the trigger control or be easily movable back to it. Specifically, the Help button reveals a side navigation panel, but after the Exit the side navigation button is activated, focus is sent to the submit button instead of returning to the Help button.

  The code sample includes revealed content where focus is not returned to the trigger control after the content is closed. A successful test should identify a failure against Baseline 2.B Focus Order.
result: Fail
