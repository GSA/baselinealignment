descr: |
  Text entered in text-based form controls must resize fully when page text is resized to at least 200 percent. Specifically, the contact form includes text-based inputs for Name and Email and a Message textarea, with no snippet code shown that prevents entered text from resizing with browser zoom.

  The code sample includes text-based form controls whose entered text is intended to resize with browser zoom. A successful test should identify a pass against Baseline 22.A Resize Text.
