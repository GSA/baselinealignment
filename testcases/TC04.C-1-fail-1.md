  Components that have the same functionality within a set of web pages must have identical associated text. Specifically, the search function appears on both the Homepage and About Us page, but the associated button text is “Search” on the Homepage and “Find” on the About Us page.

  The code sample includes components with the same functionality across multiple pages that have different associated text. A successful test should identify a failure against Baseline 4.C Consistent Identification.
