layout: testcase

title: Data table incorrectly using elements and roles


tcid: TC12.A-4-fail-6
standard: WCAG
standard-ref: 1.3.1

descr: | 
    
    Data tables that are defined using the ARIA `role="grid"` is not making use of the native `<table>` element and structure and also not appropriately assigning `role="column/rowheader"`. Each column header must have `role="columnheader"` and each row header must have `role="rowheader"`. This table in the sample code uses ARIA `role="grid"` and doesn't have the role assigned correctly. 

app-baseline: | 
    [12.1 Test Procedure for Data Tables](https://ictbaseline.access-board.gov/12DataTables/#12-tables)

    **Baseline Test ID:** 12.1-DataTable
    
    **Test Instruction:** 4

result: FAIL

result-descr: The table fails the baseline test because the data table has incorrect role assigned and does not use the native table element.
