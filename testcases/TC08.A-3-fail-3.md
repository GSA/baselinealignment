descr: |
  Text must meet minimum contrast requirements in each visual state, including when the text color changes on hover or focus. Specifically, the heading text changes to violet on hover against the page’s default white background, creating an insufficient contrast state for the 25px heading text.

  The code sample includes large text whose hover color does not provide sufficient contrast against the background. A successful test should identify a failure against Baseline 8.A Contrast (minimum).

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-8.A** | All visible text AND images of text (except those noted in Limitations, Assumptions, or Exceptions above). |  |
| **8.A-1** | Determine the [contrast ratio](https://www.w3.org/TR/WCAG22/#dfn-contrast-ratio) of foreground text and background. |  |
| **8.A-2** | Check that the contrast ratio is at least 4.5:1. [SC 1.4.3] |  |
| **8.A-3** | If the contrast ratio is less than 4.5:1, check that the ratio is at least 3:1 AND the font meets one of the following criteria: [SC 1.4.3] * At least 18 point (24 pixels) * At least 14 point (18.5 pixels) AND bold (at least 700 font weight) |  |
| **Result** | If both of the above checks fail, then Baseline Test 8.A-ContrastMinimum fails. |  |
