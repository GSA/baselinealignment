descr: |
  When prerecorded synchronized media is provided as a media alternative for text, all meaningful audible information in the media must be available in the text. Specifically, the page labels the video as a video alternative to the text, but the written instruction only says to take three carrots and slice them, omitting meaningful audible details provided in the media.

  The code sample includes a synchronized media alternative where all meaningful audible information is not available in the text. A successful test should identify a failure against Baseline 17.G Sync Media Alternative (Prerecorded).

| **IC-17.G** | Pre-recorded synchronized multimedia that is clearly labeled as a media alternative for text. |  |

| **17.G-2** | Play the media that is labeled as an equivalent alternative for the text. |  |
