descr: |
  When prerecorded synchronized media is provided as a media alternative for text, all meaningful visual information in the media must be available in the text. Specifically, the page labels the video as a media alternative for the text instructions, but the written instruction only says to take the carrots and cut them, omitting meaningful visual details such as the number of carrots and slice size.

  The code sample includes a synchronized media alternative where all meaningful visual information is not available in the text. A successful test should identify a failure against Baseline 17.G Sync Media Alternative (Prerecorded).

| Test Instruction | Instruction Detail | Expected Test Case Result |
|------------------|--------------------|---------------------------|
| **IC-17.G** | Pre-recorded synchronized multimedia that is clearly labeled as a media alternative for text. |  |
| **17.G-1** | Identify the text for which the media is an alternative. |  |
| **17.G-2** | Play the media that is labeled as an equivalent alternative for the text. |  |
| **17.G-3** | Check that the meaningful audible information of the media is available in the text. |  |
| **17.G-4** | Check that the meaningful visual information of the media is available in the text. |  |
| **Result** | If any of the above checks fail, then the multimedia is not a media alternative for text. Perform Baseline Tests 17.D Test Procedure for Captions (Prerecorded) and 17.E Test Procedure for Audio Description (Prerecorded) on the pre-recorded synchronized multimedia. |  |
